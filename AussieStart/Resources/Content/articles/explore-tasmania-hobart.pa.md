# ਝਲਕ
Hobart Tasmania ਦਾ ਸਭ ਤੋਂ ਮਿਲਣਸਾਰ ਗੇਟਵੇ ਹੈ — ਹਾਰਬਰ ਸ਼ਹਿਰ ਦਾ ਆਕਰਸ਼ਣ, MONA, ਅਤੇ wilderness ਕਿਨਾਰਿਆਂ ਦੀਆਂ ਡੇ ਟ੍ਰਿਪ।

# ਇਹ ਕਿਉਂ ਮਹੱਤਵਪੂਰਨ ਹੈ
ਲੰਬਾ ਵੀਕਐਂਡ ਆਦਰਸ਼ ਜੇ ਠੰਡਾ ਮੌਸਮ, ਫੂਡ ਕਲਚਰ ਅਤੇ ਕੁਦਰਤ ਚਾਹੀਦੀ ਹੋਵੇ ਬਿਨਾਂ ਵੱਡੇ ਰੋਡ itinerary ਦੇ।

# ਕਦੋਂ ਕਰੋ
ਲੰਬੇ ਦਿਨਾਂ ਲਈ ਗਰਮੀ; Aurora ਮੌਕੇ ਅਤੇ ਆਰਾਮਦਾਇਕ ਫੂਡ ਸੀਨ ਲਈ ਸਰਦੀ (ਗਰਮ ਕੱਪੜੇ ਪੈਕ ਕਰੋ)।

# ਅੰਦਾਜ਼ਨ ਫੀਸ (AUD)
- **Flights to Hobart (return)**: $180–$500+ pp
- **MONA entry**: ਅਕਸਰ ~$40–$50 adult (Tasmanians ਕਈ ਵਾਰ ਮੁਫ਼ਤ/ਡਿਸਕਾਊਂਟ — ਜਾਂਚੋ)
- **MONA ferry from Hobart**: ~$30–$50 return ਰੇਂਜ
- **kunanyi / Mount Wellington return shuttle or fuel**: $20–$60
- **Port Arthur day trip (entry)**: ~$50 adult ਰੇਂਜ + ਟਰਾਂਸਪੋਰਟ
- **Bruny Island tour**: $150–$280 pp
- **Meals in Salamanca / CBD**: $25–$50 pp

# ਛੋਟਾ ਪ੍ਰੋਗਰਾਮ (3 ਦਿਨ)
**ਦਿਨ 1:** Salamanca / waterfront → Battery Point ਵਾਕ → Signal Station ਵਿਊ  
**ਦਿਨ 2:** MONA ਫੈਰੀ ਦਿਨ  
**ਦਿਨ 3:** ਸਵੇਰ kunanyi/Mount Wellington **ਜਾਂ** Bruny/Port Arthur ਲੰਬਾ ਦਿਨ

# ਵਿਚਕਾਰ ਘੁੰਮਣ ਵਾਲੀਆਂ ਥਾਵਾਂ
- **Salamanca Place**
- **Battery Point cottages**
- **Tasman Bridge lookout areas**
- **Richmond** (ਡਰਾਈਵ ਕਰੋ ਤਾਂ) — Port Arthur ਰੂਟ ਤੇ ਇਤਿਹਾਸਕ ਬ੍ਰਿਜ ਟਾਊਨ
- **Kettering** ਫੈਰੀ ਟਰਮੀਨਲ (Bruny ਲਈ)
- **Mountain lookouts** kunanyi ਰੋਡ ਤੇ (ਮੌਸਮ ਤੇ ਨਿਰਭਰ)

# ਆਮ ਗਲਤੀਆਂ
- ਪਹਾੜ ਦਾ ਮੌਸਮ ਨਾ ਜਾਂਚਣਾ (ਸੜਕ ਬੰਦ ਹੋ ਸਕਦੀ ਹੈ)
- ਸਿਰਫ਼ MONA ਫੈਰੀ ਬੁੱਕ ਕਰਨਾ ਅਤੇ ਰੁਝੇ ਦਿਨਾਂ ਤੇ timed entry ਲੋੜ ਛੱਡਣਾ
- ਇੱਕ ਦਿਨ ਵਿੱਚ Port Arthur + Bruny ਭਰ ਦੇਣਾ

# ਅਕਸਰ ਪੁੱਛੇ ਜਾਣ ਵਾਲੇ ਸਵਾਲ
**ਕੀ ਕਾਰ ਜ਼ਰੂਰੀ ਹੈ?** ਮਦਦਗਾਰ, ਪਰ MONA + Hobart walkables ਟਰਾਂਸਫਰ ਨਾਲ ਚੱਲਦੇ ਹਨ।
**ਘੱਟੋ-ਘੱਟ ਕਿੰਨੇ ਦਿਨ?** 2–3 ਪੂਰੇ ਦਿਨ ਸਹੀ ਲੱਗਦੇ ਹਨ।

# ਲਾਭਦਾਇਕ ਸ਼ਬਦ

- **MONA**: Museum of Old and New Art
