# ਸੰਖੇਪ
ਲੀਜ਼ ਮਿਲਦਿਆਂ ਬਿਜਲੀ, ਕਈ ਵਾਰ ਗੈਸ ਅਤੇ ਇੰਟਰਨੈੱਟ ਆਪਣੇ ਨਾਂ ’ਤੇ ਲਗਾਉਣਾ ਪੈਂਦਾ ਹੈ। AussieStart ਰਿਟੇਲਰ ਨਾਲ ਸਾਈਨ-ਅੱਪ ਨਹੀਂ ਕਰਦਾ।

# ਇਹ ਕਿਉਂ ਜ਼ਰੂਰੀ ਹੈ
ਬਿਜਲੀ/ਇੰਟਰਨੈੱਟ ਬਿਨਾਂ ਨੌਕਰੀ, TFN ਕੋਡ ਅਤੇ ਨਕਸ਼ਾ ਔਖੇ ਹੋ ਜਾਂਦੇ ਹਨ।

# ਕਦੋਂ ਕਰੋ
ਲੀਜ਼ ਦੀ ਸ਼ੁਰੂ ਤਾਰੀਖ ਪੱਕੀ ਹੁੰਦਿਆਂ। ਕਨੈਕਸ਼ਨ ਵਿੱਚ ਕੁਝ ਦਿਨ ਲੱਗ ਸਕਦੇ ਹਨ।

# ਲੋੜੀਂਦੀਆਂ ਚੀਜ਼ਾਂ
- ਪਤਾ ਅਤੇ ਮੂਵ-ਇਨ ਤਾਰੀਖ
- ਫੋਟੋ ID
- ਬੈਂਕ/ਕਾਰਡ
- ਸ਼ੇਅਰ ਹਾਊਸ ਵਿੱਚ ਹੈੱਡ ਟੈਨੈਂਟ ਦੀ ਇਜਾਜ਼ਤ

# ਕਦਮ-ਦਰ-ਕਦਮ
1. ਏਜੰਟ/ਹਾਊਸਮੇਟ ਤੋਂ ਪੁੱਛੋ ਬਿਲ ਕਿਸ ਦੇ ਨਾਂ ’ਤੇ ਹਨ।
2. ਅਧਿਕਾਰਤ ਤੁਲਨਾ ਸਾਈਟ ਵੇਖੋ, ਫਿਰ **ਰਿਟੇਲਰ ਦੀ ਆਪਣੀ ਸਾਈਟ** ’ਤੇ ਸਾਈਨ ਅੱਪ ਕਰੋ।
3. ਮੂਵ-ਇਨ ਦਿਨ ਮੀਟਰ ਦੀਆਂ ਫੋਟੋਆਂ ਲਓ।
4. ਇੰਟਰਨੈੱਟ ਲਈ ਅਧਿਕਾਰਤ NBN ਚੈਕਰ ਵਰਤੋ।
5. ਪਹਿਲੇ ਬਿਲ ਲਈ ਰਿਮਾਈਂਡਰ ਲਾਓ।
