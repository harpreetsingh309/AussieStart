# ਝਲਕ
ਲੋਕਲ ਆਸਟ੍ਰੇਲੀਅਨ SIM (ਜਾਂ eSIM) ਬੈਂਕ, ਡਿਲੀਵਰੀ, TFN ਅਤੇ ਜਾਬ ਐਪਲੀਕੇਸ਼ਨ ਲਈ ਲੋਕਲ ਨੰਬਰ ਦਿੰਦਾ ਹੈ।

# ਇਹ ਕਿਉਂ ਮਹੱਤਵਪੂਰਨ ਹੈ
ਕਈ ਸੇਵਾਵਾਂ SMS ਕੋਡ ਭੇਜਦੀਆਂ ਹਨ। ਲੋਕਲ ਨੰਬਰ ਤੋਂ ਬਿਨਾਂ ਅਕਾਊਂਟ ਸੈੱਟਅੱਪ ਅਟਕ ਜਾਂਦਾ ਹੈ।

# ਕਦੋਂ ਕਰੋ
ਦਿਨ 1 — ਆਦਰਸ਼ ਰੂਪ ਵਿੱਚ ਏਅਰਪੋਰਟ ਤੇ ਜਾਂ ਉਤਰਨ ਵਾਲੇ ਦਿਨ ਦੁਪਹਿਰ ਤੱਕ।

# ਲੋੜੀਂਦੀਆਂ ਚੀਜ਼ਾਂ
- ਪ੍ਰੀਪੇਡ ID ਚੈੱਕ ਲਈ ਪਾਸਪੋਰਟ (ਨਿਯਮ ਪ੍ਰੋਵਾਈਡਰ ਅਨੁਸਾਰ ਵੱਖ)
- ਅਨਲਾਕਡ ਫ਼ੋਨ (ਜਾਂ dual-SIM / eSIM ਸਮਰੱਥ)
- ਪੇਮੈਂਟ ਤਰੀਕਾ

# ਕਦਮ-ਦਰ-ਕਦਮ ਗਾਈਡ
1. ਜਦ ਤੱਕ ਮਾਲਕ ਪਲਾਨ ਨਾ ਦੇਵੇ, ਪਹਿਲਾਂ ਪ੍ਰੀਪੇਡ ਚੁਣੋ।
2. ਜਿੱਥੇ ਰਹਿੰਦੇ ਹੋ ਉੱਥੇ ਕਵਰੇਜ ਲਈ Optus, Telstra, Vodafone ਅਤੇ MVNO ਦੀ ਤੁਲਨਾ ਕਰੋ।
3. ਫਿਜ਼ੀਕਲ SIM ਖਰੀਦੋ ਜਾਂ eSIM ਐਕਟੀਵੇਟ ਕਰੋ।
4. ਇੰਸਟਾਲ ਕਰੋ, ਰੀਸਟਾਰਟ ਕਰੋ, ਅਤੇ ਮੋਬਾਈਲ ਡਾਟਾ ਚਾਲੂ ਕਰੋ।
5. ਨਵਾਂ ਨੰਬਰ ਸੇਵ ਕਰੋ ਅਤੇ ਬੈਂਕਿੰਗ / ਯੂਨੀਵਰਸਿਟੀ ਕਾਂਟੈਕਟ ਅਪਡੇਟ ਕਰੋ।

# ਆਮ ਗਲਤੀਆਂ
- ਆਪਣੇ ਸਬਅਰਬ ਵਿੱਚ ਖਰਾਬ ਕਵਰੇਜ ਵਾਲਾ ਪਲਾਨ ਖਰੀਦਣਾ
- ਮਹਿੰਗਾ ਇੰਟਰਨੈਸ਼ਨਲ ਰੋਮਿੰਗ ਬੰਦ ਕਰਨਾ ਭੁੱਲਣਾ
- ਐਕਟੀਵੇਸ਼ਨ ਸਫਲ ਹੋਣ ਤੱਕ ਪੈਕੇਜਿੰਗ ਨਾ ਰੱਖਣਾ

# ਅਕਸਰ ਪੁੱਛੇ ਜਾਣ ਵਾਲੇ ਸਵਾਲ
**Prepaid ਜਾਂ postpaid?** ਨਵੇਂ ਆਉਣ ਵਾਲਿਆਂ ਲਈ prepaid ਆਸਾਨ ਹੈ।
**ਕੀ SIM ਲਈ TFN ਚਾਹੀਦਾ ਹੈ?** ਨਹੀਂ।

# ਲਾਭਦਾਇਕ ਸ਼ਬਦ
- **MVNO**: ਛੋਟੀਆਂ ਬ੍ਰਾਂਡ ਜੋ ਵੱਡੇ ਨੈੱਟਵਰਕ ਵਰਤਦੀਆਂ ਹਨ
- **eSIM**: ਨਵੇਂ ਫ਼ੋਨ ਵਿੱਚ ਬਣੀ ਡਿਜੀਟਲ SIM

# ਅਧਿਕਾਰਤ ਲਿੰਕ
ਖਰੀਦਣ ਤੋਂ ਪਹਿਲਾਂ ਹਰ ਕੈਰੀਅਰ ਦਾ ਕਵਰੇਜ ਮੈਪ ਵੇਖੋ।

# ਸਬੰਧਤ ਲੇਖ
ਅੱਗੇ: ਬੈਂਕ ਅਕਾਊਂਟ ਖੋਲ੍ਹੋ, ਫਿਰ TFN ਲਈ ਅਰਜ਼ੀ ਦਿਓ।
