# Overview
Local **councils** run libraries, hard-rubbish, parking permits, and many free community programs. State libraries and your council website are the official sources. AussieStart does not issue library cards.

# Why this matters
A library card often means free Wi‑Fi, English conversation groups, and printing — useful in week 1 before home internet is on.

# When to do it
Once you have a local address (a lease, share-house letter, or official mail).

# Requirements
- Photo ID
- Proof of address (what the council lists)
- Time to find the **correct** council (suburbs can sit on a boundary)

# Step-by-step guide
1. Find your council using the official directory for {{state.short}} (links below).
2. Open the council’s own `.gov.au` site (or the listed library site). Search “library membership”.
3. Join in person or online as that council allows. Ask about free Wi‑Fi and holds.
4. Check bin collection, parking permits, and hard-rubbish bookings on the same council site.
5. For statewide catalogues, also see the state library links.

# Common mistakes
- Paying a third-party site for a “library card”
- Using the neighbouring council’s bins (fines happen)
- Missing that some programs need a local address, not a hotel
