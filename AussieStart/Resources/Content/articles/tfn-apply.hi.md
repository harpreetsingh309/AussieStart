# अवलोकन
आपका Tax File Number (TFN) ऑस्ट्रेलिया में आपका टैक्स ID है।

# यह क्यों ज़रूरी है
बिना TFN के नियोक्ता ऊँची दर से टैक्स काट सकते हैं।

# कब करें
जैसे ही लोकल पता और फ़ोन हो — अक्सर दिन 2–5।

# ज़रूरी चीज़ें
- पासपोर्ट और वीज़ा डिटेल्स
- ऑस्ट्रेलियन पता
- लोकल फ़ोन नंबर और ईमेल

# कदम-दर-कदम गाइड
1. ज़रूरत हो तो myGov अकाउंट बनाएँ।
2. अपने वीज़ा के अनुसार ATO / myGov मार्ग से ऑनलाइन TFN के लिए आवेदन करें।
3. अपना रेफ़रेंस नंबर संभालकर रखें।
4. मिलने पर सुरक्षित रखें — कभी सार्वजनिक रूप से पोस्ट न करें।
5. नियोक्ता को केवल उनके आधिकारिक फ़ॉर्म से दें।

# आम गलतियाँ
- Facebook ग्रुप में अपना TFN शेयर करना
- काम शुरू करने के बाद तक आवेदन टालना
- TFN को ABN से भ्रमित करना

# अक्सर पूछे जाने वाले सवाल
**क्या TFN और ABN एक ही हैं?** नहीं। ABN बिज़नेस/सोल ट्रेडर के लिए है।
**क्या शुल्क लगता है?** आधिकारिक चैनल से TFN आवेदन मुफ़्त है।

# उपयोगी शब्द
- **PAYG**: वेतन से Pay As You Go टैक्स काटना
- **myGov**: सरकारी सेवाओं का पोर्टल

# आधिकारिक लिंक
- ato.gov.au
- my.gov.au
