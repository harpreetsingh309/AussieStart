# ਝਲਕ
ਤਨਖਾਹ, ਕਿਰਾਇਆ ਅਤੇ ਰੋਜ਼ਾਨਾ ਖਰਚ ਲਈ ਆਸਟ੍ਰੇਲੀਅਨ ਬੈਂਕ ਅਕਾਊਂਟ ਜ਼ਰੂਰੀ ਹੈ।

# ਇਹ ਕਿਉਂ ਮਹੱਤਵਪੂਰਨ ਹੈ
ਮਾਲਕ ਅਤੇ Centrelink (ਜੇ ਯੋਗ ਹੋਵੋ) ਆਮ ਤੌਰ ਤੇ ਲੋਕਲ BSB ਅਤੇ ਅਕਾਊਂਟ ਡੀਟੇਲ ਮੰਗਦੇ ਹਨ।

# ਕਦੋਂ ਕਰੋ
ਪਹਿਲੇ 1–3 ਦਿਨਾਂ ਵਿੱਚ।

# ਲੋੜੀਂਦੀਆਂ ਚੀਜ਼ਾਂ
ਆਮ ਤੌਰ ਤੇ ਮੰਗੇ ਜਾਣ ਵਾਲੇ ਦਸਤਾਵੇਜ਼ (ਬੈਂਕ ਅਨੁਸਾਰ ਵੱਖ ਹੋ ਸਕਦੇ ਹਨ):
- ਪਾਸਪੋਰਟ
- ਵੀਜ਼ਾ ਗ੍ਰਾਂਟ / ਰਹਿਣ ਦਾ ਸਬੂਤ
- ਆਸਟ੍ਰੇਲੀਅਨ ਪਤਾ (ਅਸਥਾਈ ਵੀ ਚੱਲ ਸਕਦਾ ਹੈ)
- ਕਈ ਵਾਰ ਦੂਜੀ ID ਜਾਂ ਸਟੂਡੈਂਟ ਐਨਰੋਲਮੈਂਟ ਲੈਟਰ

# ਕਦਮ-ਦਰ-ਕਦਮ ਗਾਈਡ
1. ਵਿਦੇਸ਼ੀ ID ਸਪੋਰਟ ਲਈ ਵੱਡੇ ਬੈਂਕ ਅਤੇ ਨਿਓ-ਬੈਂਕ ਦੀ ਤੁਲਨਾ ਕਰੋ।
2. ਜੇ ਔਨਲਾਈਨ ਔਨਬੋਰਡਿੰਗ ਓਵਰਸੀਜ਼ ID ਰੱਦ ਕਰੇ ਤਾਂ ਬ੍ਰਾਂਚ ਅਪਾਇੰਟਮੈਂਟ ਬੁੱਕ ਕਰੋ।
3. ਪਹਿਲਾਂ ਟ੍ਰਾਂਜ਼ੈਕਸ਼ਨ ਅਕਾਊਂਟ ਖੋਲ੍ਹੋ।
4. ਡੈਬਿਟ ਕਾਰਡ / ਡਿਜੀਟਲ ਵਾਲਿਟ ਐਕਟੀਵੇਟ ਕਰੋ।
5. ਤਿਆਰ ਹੋਣ ਤੇ ਆਪਣੇ ਮੋਬਾਈਲ ਨੰਬਰ ਨਾਲ PayID ਸੈੱਟ ਕਰੋ।

# ਆਮ ਗਲਤੀਆਂ
- ਹਫ਼ਤੇ ਉਡੀਕ ਕੇ ਉੱਚੀ ਫੀਸ ਵਾਲੇ ਓਵਰਸੀਜ਼ ਅਕਾਊਂਟ ਵਿੱਚ ਤਨਖਾਹ ਲੈਣਾ
- ਬੈਂਕ ਹੋਣ ਦਾ ਦਾਅਵਾ ਕਰਨ ਵਾਲੀ ਕਾਲ ਤੇ OTP ਕਿਸੇ ਨੂੰ ਦੱਸਣਾ
- ਗਲਤ ਅਕਾਊਂਟ ਟਾਈਪ ਤੇ ਮਹੀਨਾਵਾਰ ਫੀਸ ਨਜ਼ਰਅੰਦਾਜ਼ ਕਰਨਾ

# ਅਕਸਰ ਪੁੱਛੇ ਜਾਣ ਵਾਲੇ ਸਵਾਲ
**BSB ਕੀ ਹੈ?** ਤੁਹਾਡੇ ਅਕਾਊਂਟ ਨੰਬਰ ਨਾਲ ਵਰਤਿਆ ਜਾਣ ਵਾਲਾ 6-ਅੰਕਾਂ ਦਾ ਬੈਂਕ/ਰਾਜ/ਬ੍ਰਾਂਚ ਕੋਡ।
**PayID ਕੀ ਹੈ?** ਤੁਹਾਡੇ ਫ਼ੋਨ/ਈਮੇਲ ਨਾਲ ਜੁੜਿਆ ਪੇਮੈਂਟ ਐਡਰੈੱਸ।

# ਲਾਭਦਾਇਕ ਸ਼ਬਦ
- **Osko**: ਭਾਗ ਲੈਣ ਵਾਲੇ ਬੈਂਕਾਂ ਵਿਚਕਾਰ ਲਗਭਗ ਤੁਰੰਤ ਟ੍ਰਾਂਸਫਰ
- **Debit card**: ਅਕਾਊਂਟ ਤੋਂ ਤੁਹਾਡੇ ਆਪਣੇ ਪੈਸੇ ਖਰਚ ਕਰਦਾ ਹੈ

# ਅਧਿਕਾਰਤ ਲਿੰਕ
- ਬੈਂਕਿੰਗ ਬੇਸਿਕਸ ਲਈ moneysmart.gov.au

# ਸਬੰਧਤ ਲੇਖ
ਬੈਂਕਿੰਗ ਤੋਂ ਬਾਅਦ: TFN ਲਈ ਅਰਜ਼ੀ ਦਿਓ ਅਤੇ ਟਰਾਂਸਪੋਰਟ ਪੇਮੈਂਟ ਸੈੱਟ ਕਰੋ।
