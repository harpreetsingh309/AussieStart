# अवलोकन
Blue Mountains सिडनी से क्लासिक डे ट्रिप हैं — शहर के पश्चिम में escarpment व्यू, गाँव और bushwalk।

# यह क्यों ज़रूरी है
आसान पब्लिक ट्रांसपोर्ट पहुँच, बड़े व्यू, और ऑस्ट्रेलियन नेशनल पार्क का सौम्य परिचय।

# कब करें
वीकडे या वीकेंड की जल्दी शुरुआत लक्ष्य रखें। सुबह कोहरा व्यू छुपा सकता है — दोपहर अक्सर साफ़ होती है।

# अनुमानित शुल्क (AUD)
- **Train Sydney ↔ Katoomba (Opal / adult return zone-style)**: अक्सर ~$10–$20 Opal caps/डिस्काउंट के साथ बदलते हैं — Transport NSW जाँचें
- **Scenic World rides (optional)**: ~$50–$60 adult day pass रेंज
- **Echo Point / Three Sisters lookouts**: मुफ़्त
- **National park vehicle day pass (if driving)**: NSW National Parks मौजूदा शुल्क जाँचें (~$8–$12 class वाहन अक्सर)
- **Lunch in Katoomba / Leura**: $20–$40 pp
- **Guided day tour from Sydney**: $140–$250 pp

# छोटा कार्यक्रम (ट्रेन से 1 दिन)
1. सुबह ट्रेन **Katoomba** तक
2. **Echo Point** (Three Sisters) तक वॉक या बस
3. ऊर्जा हो तो छोटा **Prince Henry Cliff Walk** हिस्सा
4. **Katoomba** या सुंदर **Leura** गाँव में लंच
5. वैकल्पिक: **Scenic World** या **Wentworth Falls** lookout
6. शाम सिडनी वापस ट्रेन

# बीच में घूमने की जगहें
- **Strathfield / Parramatta** — केवल अगर काम जोड़ रहे हों; वरना Mountains ट्रेन पर रहें
- **Glenbrook** — ड्राइव करते हों तो गेटवे टाउन
- **Wentworth Falls** — वॉटरफ़ॉल lookout
- **Leura** — कैफ़े, बुटीक, क्लिफ़ वॉक
- **Katoomba** — Echo Point, टाउन सेंटर
- **Blackheath** (कार/अतिरिक्त समय हो तो) — Govetts Leap lookout

# आम गलतियाँ
- स्टेशन और Echo Point के बीच वॉक समय कम आँकना
- केवल Scenic World देखना और मुफ़्त lookout छोड़ना
- गीले boardwalk पर सिटी जूते पहनना

# अक्सर पूछे जाने वाले सवाल
**क्या कार ज़रूरी है?** नहीं — ट्रेन + लोकल बस/वॉक अच्छी तरह काम करती है।
**क्या ठंड है?** अक्सर सिडनी से ठंडा — एक लेयर साथ रखें।

# उपयोगी शब्द
- **Escarpment**: पठार का तेज़ क्लिफ़ किनारा
- **Boardwalk**: सुरक्षा के लिए बना वॉकिंग पाथ
