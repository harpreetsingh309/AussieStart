# अवलोकन
वेतन, किराया और रोज़मर्रा खर्च के लिए ऑस्ट्रेलियन बैंक अकाउंट ज़रूरी है।

# यह क्यों ज़रूरी है
नियोक्ता और Centrelink (अगर पात्र हों) आमतौर पर लोकल BSB और अकाउंट डिटेल्स माँगते हैं।

# कब करें
पहले 1–3 दिनों में।

# ज़रूरी चीज़ें
आमतौर पर माँगे जाने वाले दस्तावेज़ (बैंक के हिसाब से अलग हो सकते हैं):
- पासपोर्ट
- वीज़ा ग्रांट / ठहरने का सबूत
- ऑस्ट्रेलियन पता (अस्थायी भी चल सकता है)
- कभी-कभी दूसरी ID या स्टूडेंट एनरोलमेंट लेटर

# कदम-दर-कदम गाइड
1. विदेशी ID सपोर्ट के लिए बड़े बैंक और नियो-बैंक की तुलना करें।
2. अगर ऑनलाइन ऑनबोर्डिंग ओवरसीज़ ID अस्वीकार करे तो ब्रांच अपॉइंटमेंट बुक करें।
3. पहले ट्रांज़ैक्शन अकाउंट खोलें।
4. डेबिट कार्ड / डिजिटल वॉलेट सक्रिय करें।
5. तैयार होने पर अपने मोबाइल नंबर से PayID सेट करें।

# आम गलतियाँ
- हफ़्तों इंतज़ार करके ऊँचे शुल्क वाले ओवरसीज़ अकाउंट में सैलरी लेना
- बैंक होने का दावा करने वाले कॉल पर OTP किसी को बताना
- गलत अकाउंट टाइप पर मासिक शुल्क नज़रअंदाज़ करना

# अक्सर पूछे जाने वाले सवाल
**BSB क्या है?** आपके अकाउंट नंबर के साथ इस्तेमाल होने वाला 6-अंकों का बैंक/राज्य/ब्रांच कोड।
**PayID क्या है?** आपके फ़ोन/ईमेल से जुड़ा पेमेंट एड्रेस।

# उपयोगी शब्द
- **Osko**: भाग लेने वाले बैंकों के बीच लगभग तुरंत ट्रांसफर
- **Debit card**: अकाउंट से आपके अपने पैसे खर्च करता है
