# ਝਲਕ
Blue Mountains ਸਿਡਨੀ ਤੋਂ ਕਲਾਸਿਕ ਡੇ ਟ੍ਰਿਪ ਹਨ — ਸ਼ਹਿਰ ਦੇ ਪੱਛਮ ਵਿੱਚ escarpment ਵਿਊ, ਪਿੰਡ ਅਤੇ bushwalk।

# ਇਹ ਕਿਉਂ ਮਹੱਤਵਪੂਰਨ ਹੈ
ਆਸਾਨ ਪਬਲਿਕ ਟਰਾਂਸਪੋਰਟ ਪਹੁੰਚ, ਵੱਡੇ ਵਿਊ, ਅਤੇ ਆਸਟ੍ਰੇਲੀਅਨ ਨੈਸ਼ਨਲ ਪਾਰਕ ਦਾ ਨਰਮ ਪਰਿਚਯ।

# ਕਦੋਂ ਕਰੋ
ਵੀਕਡੇ ਜਾਂ ਵੀਕਐਂਡ ਦੀ ਜਲਦੀ ਸ਼ੁਰੂਆਤ ਟੀਚਾ ਰੱਖੋ। ਸਵੇਰ ਨੂੰ ਧੁੰਦ ਵਿਊ ਛੁਪਾ ਸਕਦੀ ਹੈ — ਦੁਪਹਿਰ ਅਕਸਰ ਸਾਫ਼ ਹੁੰਦੀ ਹੈ।

# ਅੰਦਾਜ਼ਨ ਫੀਸ (AUD)
- **Train Sydney ↔ Katoomba (Opal / adult return zone-style)**: ਅਕਸਰ ~$10–$20 Opal caps/ਡਿਸਕਾਊਂਟ ਨਾਲ ਬਦਲਦੇ ਹਨ — Transport NSW ਜਾਂਚੋ
- **Scenic World rides (optional)**: ~$50–$60 adult day pass ਰੇਂਜ
- **Echo Point / Three Sisters lookouts**: ਮੁਫ਼ਤ
- **National park vehicle day pass (if driving)**: NSW National Parks ਮੌਜੂਦਾ ਫੀਸ ਜਾਂਚੋ (~$8–$12 class ਵਾਹਨ ਅਕਸਰ)
- **Lunch in Katoomba / Leura**: $20–$40 pp
- **Guided day tour from Sydney**: $140–$250 pp

# ਛੋਟਾ ਪ੍ਰੋਗਰਾਮ (ਟ੍ਰੇਨ ਨਾਲ 1 ਦਿਨ)
1. ਸਵੇਰ ਟ੍ਰੇਨ **Katoomba** ਤੱਕ
2. **Echo Point** (Three Sisters) ਤੱਕ ਵਾਕ ਜਾਂ ਬੱਸ
3. ਊਰਜਾ ਹੋਵੇ ਤਾਂ ਛੋਟਾ **Prince Henry Cliff Walk** ਹਿੱਸਾ
4. **Katoomba** ਜਾਂ ਸੁੰਦਰ **Leura** ਪਿੰਡ ਵਿੱਚ ਲੰਚ
5. ਵਿਕਲਪਿਕ: **Scenic World** ਜਾਂ **Wentworth Falls** lookout
6. ਸ਼ਾਮ ਸਿਡਨੀ ਵਾਪਸ ਟ੍ਰੇਨ

# ਵਿਚਕਾਰ ਘੁੰਮਣ ਵਾਲੀਆਂ ਥਾਵਾਂ
- **Strathfield / Parramatta** — ਸਿਰਫ਼ ਜੇ ਕੰਮ ਜੋੜ ਰਹੇ ਹੋਵੋ; ਨਹੀਂ ਤਾਂ Mountains ਟ੍ਰੇਨ ਤੇ ਰਹੋ
- **Glenbrook** — ਡਰਾਈਵ ਕਰਦੇ ਹੋਵੋ ਤਾਂ ਗੇਟਵੇ ਟਾਊਨ
- **Wentworth Falls** — ਵਾਟਰਫਾਲ lookout
- **Leura** — ਕੈਫੇ, ਬੂਟੀਕ, ਕਲਿੱਫ ਵਾਕ
- **Katoomba** — Echo Point, ਟਾਊਨ ਸੈਂਟਰ
- **Blackheath** (ਕਾਰ/ਵਾਧੂ ਸਮਾਂ ਹੋਵੇ ਤਾਂ) — Govetts Leap lookout

# ਆਮ ਗਲਤੀਆਂ
- ਸਟੇਸ਼ਨ ਅਤੇ Echo Point ਵਿਚਕਾਰ ਵਾਕ ਸਮਾਂ ਘੱਟ ਅੰਦਾਜ਼ਾ ਲਗਾਉਣਾ
- ਸਿਰਫ਼ Scenic World ਵੇਖਣਾ ਅਤੇ ਮੁਫ਼ਤ lookout ਛੱਡਣਾ
- ਗਿੱਲੇ boardwalk ਤੇ ਸਿਟੀ ਜੂਤੇ ਪਹਿਨਣਾ

# ਅਕਸਰ ਪੁੱਛੇ ਜਾਣ ਵਾਲੇ ਸਵਾਲ
**ਕੀ ਕਾਰ ਲੋੜੀਂਦੀ ਹੈ?** ਨਹੀਂ — ਟ੍ਰੇਨ + ਲੋਕਲ ਬੱਸ/ਵਾਕ ਚੰਗੀ ਤਰ੍ਹਾਂ ਕੰਮ ਕਰਦੀ ਹੈ।
**ਕੀ ਠੰਡ ਹੈ?** ਅਕਸਰ ਸਿਡਨੀ ਤੋਂ ਠੰਡਾ — ਇੱਕ ਲੇਅਰ ਨਾਲ ਰੱਖੋ।

# ਲਾਭਦਾਇਕ ਸ਼ਬਦ
- **Escarpment**: ਪਠਾਰ ਦਾ ਤੇਜ਼ ਕਲਿੱਫ ਕਿਨਾਰਾ
- **Boardwalk**: ਸੁਰੱਖਿਆ ਲਈ ਬਣਾਇਆ ਵਾਕਿੰਗ ਪਾਥ
