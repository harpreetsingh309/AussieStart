# ਝਲਕ
ਤੁਹਾਡਾ Tax File Number (TFN) ਆਸਟ੍ਰੇਲੀਆ ਵਿੱਚ ਤੁਹਾਡਾ ਟੈਕਸ ID ਹੈ।

# ਇਹ ਕਿਉਂ ਮਹੱਤਵਪੂਰਨ ਹੈ
ਬਿਨਾਂ TFN ਮਾਲਕ ਉੱਚੀ ਦਰ ਤੇ ਟੈਕਸ ਕੱਟ ਸਕਦੇ ਹਨ।

# ਕਦੋਂ ਕਰੋ
ਜਿਵੇਂ ਹੀ ਲੋਕਲ ਪਤਾ ਅਤੇ ਫ਼ੋਨ ਹੋਵੇ — ਅਕਸਰ ਦਿਨ 2–5।

# ਲੋੜੀਂਦੀਆਂ ਚੀਜ਼ਾਂ
- ਪਾਸਪੋਰਟ ਅਤੇ ਵੀਜ਼ਾ ਡੀਟੇਲ
- ਆਸਟ੍ਰੇਲੀਅਨ ਪਤਾ
- ਲੋਕਲ ਫ਼ੋਨ ਨੰਬਰ ਅਤੇ ਈਮੇਲ

# ਕਦਮ-ਦਰ-ਕਦਮ ਗਾਈਡ
1. ਲੋੜ ਹੋਵੇ ਤਾਂ myGov ਅਕਾਊਂਟ ਬਣਾਓ।
2. ਆਪਣੇ ਵੀਜ਼ਾ ਅਨੁਸਾਰ ATO / myGov ਰਾਹ ਤੋਂ ਔਨਲਾਈਨ TFN ਲਈ ਅਰਜ਼ੀ ਦਿਓ।
3. ਆਪਣਾ ਰੈਫਰੈਂਸ ਨੰਬਰ ਸਾਂਭ ਕੇ ਰੱਖੋ।
4. ਮਿਲਣ ਤੇ ਸੁਰੱਖਿਅਤ ਰੱਖੋ — ਕਦੇ ਜਨਤਕ ਤੌਰ ਤੇ ਪੋਸਟ ਨਾ ਕਰੋ।
5. ਮਾਲਕ ਨੂੰ ਸਿਰਫ਼ ਉਨ੍ਹਾਂ ਦੇ ਅਧਿਕਾਰਤ ਫਾਰਮ ਰਾਹੀਂ ਦਿਓ।

# ਆਮ ਗਲਤੀਆਂ
- Facebook ਗਰੁੱਪ ਵਿੱਚ ਆਪਣਾ TFN ਸਾਂਝਾ ਕਰਨਾ
- ਕੰਮ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਬਾਅਦ ਤੱਕ ਅਰਜ਼ੀ ਟਾਲਣਾ
- TFN ਨੂੰ ABN ਨਾਲ ਉਲਝਾਉਣਾ

# ਅਕਸਰ ਪੁੱਛੇ ਜਾਣ ਵਾਲੇ ਸਵਾਲ
**ਕੀ TFN ਅਤੇ ABN ਇੱਕੋ ਹਨ?** ਨਹੀਂ। ABN ਬਿਜ਼ਨਸ/ਸੋਲ ਟ੍ਰੇਡਰ ਲਈ ਹੈ।
**ਕੀ ਫੀਸ ਲੱਗਦੀ ਹੈ?** ਅਧਿਕਾਰਤ ਚੈਨਲ ਤੋਂ TFN ਅਰਜ਼ੀ ਮੁਫ਼ਤ ਹੈ।

# ਲਾਭਦਾਇਕ ਸ਼ਬਦ
- **PAYG**: ਤਨਖਾਹ ਤੋਂ Pay As You Go ਟੈਕਸ ਕੱਟਣਾ
- **myGov**: ਸਰਕਾਰੀ ਸੇਵਾਵਾਂ ਦਾ ਪੋਰਟਲ

# ਅਧਿਕਾਰਤ ਲਿੰਕ
- ato.gov.au
- my.gov.au

# ਸਬੰਧਤ ਲੇਖ
ਅੱਗੇ: ਹੈਲਥਕੇਅਰ ਬੇਸਿਕਸ ਅਤੇ ਆਪਣੇ ਵੀਜ਼ਾ ਲਈ Medicare ਯੋਗਤਾ।
